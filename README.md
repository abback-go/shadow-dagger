# MBHG: ECLIPSE

타격감(juice)과 비주얼을 극한으로 끌어올린, 의존성 없는 단일 HTML 보스 액션 게임.

## 플레이

`index.html`을 브라우저로 열면 바로 실행됩니다. 별도의 빌드나 의존성 설치가 필요 없습니다.

GitHub Pages로 배포하려면 저장소 Settings → Pages에서 `master` 브랜치의 루트를 소스로 지정하세요.

## 조작

- 이동 / 점프 / 대시
- 근접 공격 및 회피
- 타이틀 화면에서 `↑ ↓` 로 메뉴 선택, `SPACE` / `ENTER` 로 결정
